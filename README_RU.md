# Loki Structures & Scepter — Fabric 1.21.1

Это **отдельный мод**, не расширение Homelander. Добавляет в новые участки обычного мира два редких здания, их обитателей и новый магический предмет **Скипетр Локи**.

## Структуры

### Дом жителей (Village Treasury)
- Небольшое деревянное здание 11×11 с каменным фундаментом, окнами, двухъярусной крышей, внутренним убранством и дорожкой.
- Внутри появляются два жителя, стоят два сундука с полезным лутом (железо, немного золота, изумруды, еда, книги).
- **Шанс Скипетра Локи — 10% на каждый сундук**. С двумя сундуками вероятность найти хотя бы один ≈ 19% (при независимых бросках).

### Укрепление разбойников (Pillager Stronghold)
- Каменное здание 13×13 с четырьмя башнями, бойницами, зубцами, казармой и дорожкой.
- Внутри появляются три разбойника и два сундука с ценным лутом: железо, золото, изумруды, алмазы, золотые яблоки и т. д.
- **Шанс Скипетра Локи — 70% на каждый сундук**. С двумя сундуками вероятность найти хотя бы один ≈ 91%.

**Генерация:** только в *новых* чанках при исследовании Верхнего мира. Используются worldgen features, а не структуры со списком `/locate structure`. Проект содержит две независимые настройки частоты:

- `src/main/resources/data/loki_structures/worldgen/placed_feature/villager_treasury.json` — `chance: 125` (попытка в среднем на 125 чанков).
- `src/main/resources/data/loki_structures/worldgen/placed_feature/pillager_stronghold.json` — `chance: 225` (попытка в среднем на 225 чанков).

Попытки могут завершиться неудачей на воде и сложном рельефе; реальная частота ниже. Обычные миры продолжают работать, но исследовать нужно новые территории. Постройки могут пересекаться с другими модами генерации.

## Скипетр Локи

- **ПКМ** — зелёный магический луч на расстояние до 24 блоков, 12 ед. базового урона (6 сердец без защиты), замедление и свечение цели на 5 секунд. Перезарядка **5 секунд**.
- **Shift + ПКМ** — иллюзия: **невидимость 12 секунд** и **скорость II на 12 секунд**. Перезарядка **18 секунд**.
- Предмет можно также получить для проверки командой:
  `/give @s loki_structures:loki_scepter`
- Иконка предмета — собственный пиксель-арт (тёмное золото + зелёный самоцвет).

## Установка и сборка

Требуется **Minecraft Java 1.21.1 + Fabric Loader + Fabric API**, Java 21 для сборки.

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте архив и загрузите его **содержимое**, включая скрытую папку `.github`, в корень репозитория.
3. Откройте **Actions → Build Loki Structures (Minecraft 1.21.1)**.
4. После успешной сборки в Artifacts загрузите `Loki-Structures-Fabric-1.21.1`.
5. Из ZIP извлеките файл `loki-structures-1.0.0.jar` и положите его в `mods` вместе с Fabric API.

Сборка также запускается через `gradle --no-daemon clean build` в Java 21.

### Настройка лута

Изменяйте JSON-файлы:
- `data/loki_structures/loot_table/chests/villager_supplies.json`
- `data/loki_structures/loot_table/chests/pillager_vault.json`

Отдельный второй пул лута определяет шанс скипетра. В первом: `weight: 1` у предмета и `weight: 9` у пустого слота (10%). Во втором: `weight: 7` у предмета и `weight: 3` у пустого (70%).

## Ограничения и проверка

Это исходный проект. JSON и архив проверены локально, **полную компиляцию Gradle и запуск в Minecraft в этой среде выполнить не удалось**. Если GitHub Actions найдёт ошибку — приложите лог `compileJava`, чтобы исправить именно эту несовместимость. Для большого мира рекомендуется сначала проверить мод на отдельной тестовой карте.
